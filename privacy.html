Privacy policy

Last updated: 22 November 2026

Who uses this app

This OAuth client exists only so its owner can run rclone against their own Google Drive. It has no other users.

Data accessed

When the owner signs in, rclone receives access to their Google Drive (the drive scope). rclone uses it to list, copy, download and checksum the owner's own files.

Where data goes

Files move only between the owner's computer and the owner's Google Drive. The sign-in token is stored in the rclone configuration file on the owner's computer. Nothing is sent to, stored on, or shared with any other server or third party, and no analytics are collected.

Google user data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
